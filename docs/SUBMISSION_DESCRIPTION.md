SoldierPhysio-bench tests whether frontier models can make a field medic's heat-casualty calls. Each model sees what a medic actually has (heart rate, skin temperature, work rate, weather, the Army TB MED 507 heat card) on real heat-chamber data with measured core temperature, and must decide keep-or-pull, apply the current heat card, and build a core-temperature estimator that beats an ECTemp-style baseline. 21 frozen tasks across 3 task types, code-graded against measured outcomes, with an LLM judge used only for reasoning quality. I tested 14 frontier models (GPT-6 Astra, Sonnet 5.5, Opus 5.5, Gemini 4 Argon, Grok 4.6 and others) via OpenRouter. Headline: the best model scores 54.5/100; keep/pull calls are right only 55% of the time, mostly through needless pulls of safe soldiers; and 18 of 28 rulebook answers recite the superseded 2003 card (40/20 work/rest) instead of the 2022 card (no limit). Models can fit a predictor, but they lack the current rulebook and the judgment to leave a hot-but-fine soldier on task.
