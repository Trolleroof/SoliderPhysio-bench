# Rulebook versus body

Status: preserved design; reference table, runner and grader are not implemented.

Give the model a weather flag, work category, a versioned TB MED 507 reference
table and a permitted wearable/workload trace. Ask for the prescribed work/rest
schedule and whether individual evidence supports an override, with supporting
evidence. The recovered plan proposed one case of this task type.

Grade table lookup independently from the physiological override component.
Lookup needs a verified table and explicit handling of its qualifications.
Override grading needs a validated decision rubric and measured outcomes;
a thermometer value alone must not silently define every operational decision.

Required before running: the versioned table with provenance, frozen input/output
cases, an explicit override rubric, deterministic grading tests and leakage
checks. This specification does not invent clinical or Army-policy thresholds.
